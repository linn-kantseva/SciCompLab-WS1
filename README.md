# SciCompLab-WS1

Worksheet 1 for Scientific Computing Lab.

## Contents

- `ASSIGNMENT.m` and `ASSIGNMENT.pdf`: a breakdown of what we have edited, with explanations.
- `mchoice.m` and `game.m`: the actual files, which contain our edits.
- `data_2_2_*.mat` and `data_2_3_*.mat`: experimental data for the experimental convergence exercises (the numbers 10, 100 and 1000 in the file names are the different sample sizes).
- `gen_human_move.m` and `game.fig`: supporting files for the game.
- `worksheet1.pdf`: the original worksheet.

## How to run

Open MATLAB in this folder and run `game.m`.
